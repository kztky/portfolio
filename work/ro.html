炉 RO｜多言語レストランLP（仮想クライアント）

訪日外国人の来店が増えている一方、Webでの多言語対応や予約導線に課題を抱える地方の飲食店を仮想クライアントとして設定した自主制作。架空の炭火料理レストラン「炉 RO」を題材に、ターゲットごとの情報の見え方を考えながら、5言語対応のランディングページを企画・設計・実装した。

Thinking Process

01 — 想定 / どんな顧客と課題を設定したか

地方で営業する飲食店が、訪日外国人の来店増加に対してWebサイトの多言語対応が追いついていない状況を想定した。日本語中心の情報設計のままでは、料理や価格、店の雰囲気、予約方法を十分に理解できず、興味を持った海外ユーザーが予約前に離脱してしまう可能性があると考えた。

02 — 課題仮説 / 何を解くべきだと考えたか

単に文章を翻訳するだけでは不十分ではないか、と仮定した。旅行者が予約前に確認したい情報や、その優先順位は言語圏や利用状況によって異なる可能性がある。そこで「翻訳の不足」だけでなく、「ターゲットごとに必要な情報へ迷わず到達できる導線がないこと」を設計上の課題として置いた。翻訳そのものではなく、情報設計と予約までの導線を解決の中心に据えている。

03 — アプローチ / 仮説をどう形にしたか

日本語・英語・中国語（簡体字／繁体字）・韓国語の5言語を想定し、各言語から料理、価格、店舗情報、予約導線へ短い距離で到達できる構成を設計した。外部ライブラリは使わず HTML / CSS / JS で実装し、表示速度を損なわない構成を優先。hreflang 属性も組み込み、多言語サイトとして検索エンジンに言語別ページを伝えられる構造にした。
