Web制作 / 2025

炉 RO｜多言語レストランLP

青森市内の炭火料理レストラン「炉 RO」のWebサイトを制作。増加する訪日外国人の予約につなげるため、5言語対応のランディングページを設計・実装した。コンセプト設計・デザイン・言語切替UI・多言語SEO対応まで一貫して担当。

種別 Web制作
技術 HTML / CSS / JS
対応言語 5言語
公開 2025年

Thinking Process

01 — 問題 / 何が課題だったか

訪日外国人が増加しているにもかかわらず、既存のWebサイトは日本語のみで構成されていた。外国語での情報提供が不十分なため、来店に興味を持った海外ユーザーが予約に至らず離脱してしまう状況が続いていた。

02 — 課題定義 / 問題をどう解釈したか

「翻訳を追加すれば解決する」という仮説を、最初に疑った。国や文化によって「何を重視するか」「どこで予約を決めるか」が異なる。英語話者はコンセプトと雰囲気を、中国語・韓国語話者はメニューと価格を早期に見たがる傾向がある。

つまり問題の本質は「翻訳の不足」ではなく、「言語ごとの導線設計がないこと」だと定義した。翻訳はあくまで手段であり、解決の本体はターゲット別の情報設計にある。

03 — アプローチ / なぜその手段を選んだか

5言語（日・英・中〈簡体字〉・繁体字・韓）に対応し、言語ごとに訴求軸とCTAを変えた導線を設計した。外部ライブラリは使わず HTML / CSS / JS のみで実装し、表示速度を最優先にした。hreflang 属性による多言語SEO対応も組み込み、各言語での検索流入を獲得できる構造にしている。
