生成AIを活用した問い合わせ対応業務の効率化提案

「AIを導入すれば効率化できる」という抽象論ではなく、問い合わせ業務のどこにAIを使い、どこを人間に残すのかまで具体化することを目的に制作した7枚の企業向け提案資料です。

Thinking Process

01 — 問題 / 何を伝える必要があったか

「生成AIを導入すると効率化できる」というだけでは、提案資料として意思決定につながりにくい。そこで、問い合わせ業務を構成する作業を分解し、AIに任せられる領域と、人間の判断を残す領域を具体的に示すことを課題にしました。

02 — 課題定義 / なぜ7枚構成にしたか

情報量を増やすのではなく、読み手が「現状を理解する → 問題を認識する → 解決方法に納得する → 次の行動を判断する」までを短時間で追えることを優先。現状・課題・分析・提案・根拠・導入手順を7枚に絞り、一本の流れとして構成しました。

03 — アプローチ / どう設計したか

調査値・予測値・他社事例を同列に扱わず、それぞれの意味が分かるようラベルと注記を分離。さらに、問い合わせを「定型」「情報検索」「判断・例外」に分け、AIと人間の役割分担をフローとして視覚化しました。装飾よりも、提案内容を誤解なく伝えることを優先しています。

1. 表紙 / 2. AI活用の現在地 / 3. 現状課題 / 4. 自動化適性分析 / 5. AIと人間の役割分担 / 6. 他社事例 / 7. 導入ロードマップ
